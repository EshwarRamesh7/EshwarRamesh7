## Featured work

### GDP Growth Prediction with Machine Learning & Explainable AI
**MSc research project | Python, Scikit-learn, XGBoost, SHAP, Power BI**

Used World Bank indicators covering 257 countries and the period 2000–2023. Combined 19 datasets, then applied feature-selection and data-quality steps to create a modelling dataset of 5,977 rows and 45 features. Compared Linear Regression, Random Forest and XGBoost. XGBoost achieved a test R² of 0.7361 and RMSE of 3.61 on the 2019–2023 holdout period. Used SHAP to interpret model predictions and built a three-page Power BI dashboard.

### Job Market Skills Intelligence — US vs India
**Python, MySQL, Excel, Power BI**

Built a workflow to compare Data Analyst job postings, skill demand and salary patterns across the US and India. Used a 134-skill vocabulary, SQL analysis and a three-page Power BI dashboard. The analysis also documents source-coverage and sample-size differences between the two markets.

[View repository](https://github.com/EshwarRamesh7/Job-Market-Skill-Demand-Analysis-US-vs-India)

### Global Retail Performance Dashboard
**Power BI, DAX, Power Query, Python**

Developed a three-page dashboard for a Global Superstore dataset with 51,290 transaction rows across 147 countries and seven markets. Built date-based measures and used decomposition analysis to investigate profitability and discount patterns.

[View repository](https://github.com/EshwarRamesh7/Global-superstore-powerbi-dashboard)
